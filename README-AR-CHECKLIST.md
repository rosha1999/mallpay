## استعادة حساب المدير

- أمر `npm run admin:create` يعمل من طرفية تفاعلية، ويطلب كلمة المرور دون إظهارها على الشاشة.
- إذا كان البريد موجوداً، يعرض الأمر تنبيهاً ويطلب كتابة `RESET` حرفياً قبل تغيير كلمة المرور وإعادة تفعيل الحساب؛ أي إدخال آخر يلغي العملية.
- إذا لم يكن البريد موجوداً، ينشئ حساب مدير جديداً.
- شغّل الأمر فقط بعد التأكد أن `DATABASE_URL` يشير إلى قاعدة بيانات MallPay الصحيحة. لتغيير حساب الموقع المنشور، نفّذ الأمر من بيئة آمنة متصلة بقاعدة بيانات الإنتاج؛ تشغيله على قاعدة محلية لن يغيّر حساب الموقع المنشور.
- لا تضع كلمة المرور في أوامر الطرفية أو سجلات النشر، ولا تضف بيانات اتصال قاعدة البيانات إلى Git.
